**Goal:** Demonstrate that the independent gate catches drift in a real coding-assistant edit, then test the same boundary in a protected PR. The present proof covers one fixed Aurora React fixture. A CSS pseudo-element copy bypass was reproduced and closed locally; a blind assistant edit has not run.

**Context:** The fixture's source gate, locked build, attestation, and Chromium checks pass. An added `content` declaration now fails with `css-content`, and a browser response mutation confirms generated copy is detected. The shared research ledger has used its one run for 30 September UTC.
