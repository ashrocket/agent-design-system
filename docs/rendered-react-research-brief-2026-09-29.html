Agent Design System / research brief / 30 September 2026

Keep the assistant inside the system

Coding assistants can read a design system and still drift from it. Our research turns the system into a contract that independent tools can enforce, then follows one authored React page from source to browser pixels.

The research finding

A prompt is useful guidance; the enforceable boundary is a reviewed contract checked outside the assistant’s writable scope. The check itself is deterministic and has no runtime model or network dependency.

The open, vendor-neutral format records tokens and rule decisions as report, coerce, reject, or ignore. adsys check reports without changing source; adsys fix writes only to an explicit output unless asked to write in place. A separate, budgeted research loop can suggest improvements without sitting in the enforcement path.

What we built and tested

Reviewed contract→Source gate→Locked build→Attestation→Chromium

The project gate inventories every file under the app root, checks generated token parity, rejects unknown source, and links static JSX classes to inspected CSS. The React host index.html and mount entry main.tsx are app-authored, exact-pinned files. The external expected contract fingerprint is mandatory for this profile, so changing manifest pins alongside code cannot create a standalone pass.

The trusted builder consumes that entry, copies the checked host, and permits five bundled source inputs plus the separately checked HTML. Two independent source locations produced the same three output bytes. The verifier then issues a fresh artifact attestation outside the app output directory.

Where the rule held

Chromium mounted one visible button, loaded the attested stylesheet, kept the approved token #2563eb, and computed the button background as rgb(37, 99, 235). It requested only the expected HTML, JavaScript, and CSS.

The honest boundary

This is one fixed static React app profile, not arbitrary app coverage. The host and entry are reviewed byte-for-byte rather than semantically parsed. The browser asserts the button’s foreground and background, plus exact text and vertical padding in the controlled edit mode. Routes, interactions, dynamic component graphs, server behavior, and full visual fidelity still need coverage.

The browser command accepts an unsigned attestation, so its source provenance depends on the trusted Python verifier-to-browser handoff. CI is wired but has not been observed remotely at an exact commit. A blind assistant run is still unmeasured; the approved edit was a controlled local experiment.
