The Verdict component shows the four outcomes of the ADSF decision tree: accept, report, coerce and reject. Each outcome has its word and a one-line meaning.

Use when: showing the result of an ADSF check, in a docs page, a report or a CLI guide.

The consumer supplies: the verdict word and the meaning of the checked value. The word is always shown with the colour.

Do: show the word in its colour and the meaning beside it. Keep the four states in this order.

Do not: show colour alone, change the words, add an icon without a word, or add a fifth state.
